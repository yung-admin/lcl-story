Date: 2026-10-04. Status: direct preferences recorded; exploration continues.

The user selected Protocol's machine decals and crisp screen UI, plus Reverence's darker mood. They want more assertive graphics in both the environment and game UI, inspired by Wipeout aesthetics. These are raster concept images; interface behaviour and fictional allocation copy do not specify new mechanics.

## Wipeout research and translation

[The official WipEout Fury environment-design diary](https://blog.playstation.com/archive/2009/07/08/wipeout-fury-developer-diary-environment-design//) describes contemporary graphic design integrated with futuristic architecture, bold structural shapes and attention to HUD clarity. We translate that principle into original LCL civic identifiers, modular typography, measured grids and environmental decals. No existing team marks or racing interface are used. The specific visual vocabulary is an authored proposal.

## User preference — 2026-10-04

- **Screen UI: Overprint.** The user specifically distinguishes actual screen UI from machine decals. They prefer Overprint's overall UI design and smaller footprint. White looks better visually to them, while the darker treatment is more comfortable for the eyes. Preserve this tradeoff; it does not reduce their preference to colour alone or approve Overprint's physical decals.
- **World treatment: Conduit.** The user likes the rounded machinery in this scene, its colouring and its highlights. They explicitly say that all machinery need not be rounded. Use these as selected qualities and a scene reference, not a universal shape rule.
- **Earlier choices remain relevant.** Protocol's machine decals and Reverence's darker mood were selected in the previous turn. The UI preference does not supersede those physical-graphics choices. No Pass verdict for Directive or Violet is inferred, and no hosted rating rows were entered from the conversation.

The user subsequently approved exploring this synthesis, physical interface states and supporting architecture. [Round 09](physical-interface-tests.md) renders Conduit's environment with Overprint's compact dark UI and selective white accents. Those new results await review; final interface behaviour and a production pipeline remain open.
