# Clean surfaces, selected details — Round 06

Before testing Opaque Signal in daylight, homes or larger infrastructure, the user requests “a style which make things super clean, so the details which are there pop a lot”. This round interprets clean as **low visual noise and deliberate detail hierarchy**. It tests the same Bowl Watch hall rather than new scenes. Opaque Signal remains the previous leading favourite, with Matte Signal the close alternative; this request does not approve a replacement.

## Design hypothesis

Give architecture, large machine panels, floor and cloth broad quiet surfaces. Concentrate small defining shapes around four serving openings/trays, bowls and hands, green state lenses, a sparse inset screen and the right repair controls. Different materials should read through shape, colour and shading rather than dense wear or texture. Remove decorative microdetail while retaining distinctive serviceable technology.

Keep the slate/bone/coral family, five people, four open trays and fixed overhead oblique/trimetric near-parallel camera. Keep continuous grounded floor, piers, staircase/gallery, bowl shelf/bench, supply pipe and repair station. These are concept comparisons rather than exact projection or engine tests. Reduced wear is an art experiment, not a new claim that all LCL infrastructure is pristine.

| [Quiet](../../../images/style-lab/round-06/r06-02-quiet-paint.png) | Quiet surfaces and broader material planes | The opaque-paint request converged toward modeled shading, close to Precision |
| [Graphic](../../../images/style-lab/round-06/r06-03-graphic.png) | Flat colour planes, angular amber patches and simpler shadow masses | Lighting changes; residual gradients exceed a strict three-value target |

All three retain five people, four trays and the main hall anchors. Floor joints, panel seams, vent positions, sparse screen diagrams and fine figure/device details differ. Smooth surfaces clearly reduce attention competition, but the images do not isolate cleanliness from exact lighting and hardware redesign.

Precision removes most small fasteners, text, wear and bank vents, while retaining lamp cages, selected panel seams and a detailed enough repair cassette. Bowls, hands, tray rims and state lights stand out against broad fields. Quiet also retains a few handles/vents. It does not convincingly become a distinct handmade painting; label its actual clean illustrated/modelled shading rather than claiming pure gouache.

The first [Graphic draft](../../../images/style-lab/round-06/r06-03-graphic-draft.png) stayed too close to the other modeled outputs. One targeted refinement asked for flat-value shading while preserving its content. The final uses large flat slate shapes and polygonal amber patches, so it provides a more distinct extreme. Cloth/material forms retain some continuous shading; no exact three-colour production shader is established.

Our provisional assessment is that cleaner fields make functional details more legible, while moving toward a more pristine atmosphere. Precision offers more tactile volume; Graphic tests the limit of reduction. These observations describe the comparison; the user preference below determines the leading reference.

## User preference — 2026-10-04

After reviewing the clean exploration, the user said: “opaque still better”. Opaque Signal remains the preferred whole-image reference over the clean round. This feedback does not establish individual trait ratings or a Pass verdict for each clean image; no hosted review votes were entered from it.

Our interpretation is that Opaque Signal's brushwork and material variation contribute atmosphere and character that the cleaner treatments lose. A possible next experiment is selective clarity around focal details within the opaque treatment. This is an authored proposal, not an approved trait rule or a request to generate another round.
